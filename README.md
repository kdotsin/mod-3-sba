Overview:
This is a website for a digital bank landing page with mobile phone responsivity and a custom menu
toggle for phones.
I used tailwind to create this project
My main challege I faced was the images that layered on top of each other and poking out of the 
webpage. Was difficult to find documentation on how to integrate the images properly. Other than 
that the work was more meticulous and had lots of attention to detail properties. 

Summary:
Main challenge was figuring out how to use absolute for the images and making sure it fit well with the other container tags. I solved this by looking through documentation and basically lots of trial and error. I kept changing the positions of the images and syntax of different tags to see what was working and what didn't. Another challenge was figuring out the mobile responsiveness and how to format it correctly. This was also lots of trial and error. If given more time I honestly would like to add more functionally and fix the webpage for sizes inbetween monitor and mobile.
